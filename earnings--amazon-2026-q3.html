Amazon: AWS 가속과 전사 FCF 부담을 같은 화면에서 봐야 합니다

AWS는 39.3% 성장했지만 최근 12개월 FCF는 유출입니다. 수요의 강도와 투자 자금 부담은 동시에 존재합니다.

Amazon · 2026-10-30 · 원문 ↗

원문 근거 50% · 공식 실적 발표와 공개 전사본의 준비 발언·일부 질의응답을 대조했습니다. 표시 비율은 실제 열독한 렌더링 본문 줄 기준의 하한이며 단어·오디오 시간 비율은 아닙니다. 음성은 청취하지 않았습니다. 제3자 전사에는 오기 가능성이 있습니다. · 작성 2026-11-02

실적: AWS와 전사 수익성을 분리합니다

연결 매출은 2,019억 달러, 영업이익은 281억 달러였습니다. AWS 매출은 460억 달러, 영업이익은 178억 달러였습니다.

AWS 성장률 39.3%와 연환산 매출 실행률 1,840억 달러는 서로 다른 표현입니다. 연환산 실행률을 2026년 실제 연간 매출로 바꾸지 않습니다.

AWS 영업이익을 AWS 매출로 나눈 마진은 약 38.7%입니다.

EPS: 전년 Anthropic 평가이익이 비교 기저입니다

이번 분기 GAAP EPS는 1.89달러, 전년은 1.95달러였습니다. 전년 3분기에는 Anthropic 투자 관련 세전 이익 95억 달러가 포함돼 있었습니다.

헤드라인 EPS 감소와 AWS 영업 성장의 방향이 다를 수 있습니다. 세금·주식 수 자료 없이 임의의 조정 EPS를 계산하지 않습니다.

투자: 현금 CapEx와 최근 12개월 FCF입니다

최근 12개월 영업현금흐름은 1,683억 달러였지만 FCF는 424억 달러 유출이었습니다. 이것은 한 분기의 FCF가 아닙니다.

2026년 현금 CapEx 전망 약 2,200억 달러는 Amazon 전사 기준입니다. 전부 AWS 또는 AI 전용 투자라고 단정하지 않으며 금융리스 포함 지표와 구분합니다.

전망: 회사 성장 발언을 실적·컨센서스와 구분합니다

4분기 매출 가이던스는 2,400억~2,470억 달러, 영업이익은 285억~335억 달러입니다.

CEO는 AWS가 2027년과 2028년 각각 40% 초과 성장할 수 있다고 전망했습니다. 이는 경영진 전망이며 이미 확정된 매출이나 외부 컨센서스가 아닙니다.

질의응답: 칩·추론 수요가 자본 회수로 이어지는가가 쟁점입니다

장기 수주와 추론 사용 증가는 공급 가시성을 높일 수 있지만, 계약 잔액을 현재 인식 매출로 합산할 수 없습니다. 투자 부담은 인도·가동·사용료·현금 수령의 순서로 확인해야 합니다.

Amazon 주주에게 중요한 조건은 AWS 성장과 마진이 유지되면서 현금 투자 증가가 둔화되는지입니다. 공급사 매출 증가는 같은 속도의 주주 수익을 보장하지 않습니다.

다음 확인: AWS 지표와 전사 현금을 연결합니다

AWS 성장, 영업마진, 수주 인식, 현금 CapEx와 FCF를 같은 기간 기준으로 추적합니다. 전사 소매·광고 사업의 기여도 별도 변수입니다.

현재 주가·동일 시각 컨센서스·추정 EPS 이력이 없어 주가 목표와 적정 멀티플은 제시하지 않습니다. 공개 제3자 전사본의 열독 범위를 명시했습니다.
